# NEXORA — Portfolio Website

Site vitrine responsive pour NEXORA, agence web.

## Lancer le site en local
Aucune installation n'est nécessaire :
1. Téléchargez ou décompressez le dossier.
2. Ouvrez `index.html` dans votre navigateur.

Pour un aperçu plus confortable, utilisez l'extension **Live Server** dans VS Code.

## Personnalisation avant publication
- Dans `index.html`, remplacez `@nexora.web` par votre vrai compte Instagram si nécessaire.
- Remplacez `contact@nexora.ma` par votre adresse e-mail réelle.
- Les projets Le Gourmet, Élise Beauty, Vista Estates et Apex Motors sont des concepts fictifs. Gardez la mention de démonstration ou remplacez-les par de vrais projets avec autorisation.
- Modifiez les textes, services et couleurs dans `index.html` et `style.css`.

## Publier sur GitHub Pages
1. Créez un dépôt GitHub, par exemple `nexora-portfolio`.
2. Importez les fichiers `index.html`, `style.css`, `script.js` et `README.md` à la racine du dépôt.
3. Dans le dépôt, ouvrez **Settings → Pages**.
4. Sous **Build and deployment**, choisissez **Deploy from a branch**.
5. Choisissez la branche `main` et le dossier `/ (root)`, puis cliquez sur **Save**.
6. Attendez la publication : GitHub affichera l'adresse de votre site dans la section Pages.
